# release-readiness

Read CLAUDE.md and docs/cli.md. Find releases held by unfinished tests or defects.

Run `npm run testing -- release-readiness`. Use values the operator supplies. Every read supports --json.

Report what the records say. List ambiguous matches and ask the operator to choose. No guessing.

No command sends a message, deploys a release or changes a vendor system.
