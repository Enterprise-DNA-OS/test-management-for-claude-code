# Selection and sources

Checked 8 October 2026. Software-testing was unused in the rebuild registry; Scoro's agency-operations family was already built tonight. TestRail is the selected incumbent.

Selection scenario: US$23,400 per year for 25 Enterprise seats, using the published US$78 monthly equivalent per seat on annual billing. This is arithmetic, not a verified customer invoice. No named NZ or AU buyer or live CRM usage was verified. The public page quotes only the per-seat price and its annual equivalent.

Scores, in charter order: annual bill 3, data-shaped 5, buyer fit 2, search demand 4, one-session buildable 5, import path 5. Total 24/30. Buyer fit is discounted because current customer use is unverified. Search score reflects multiple alternative comparison results, not measured keyword volume.

Other candidates considered: Sastrify 20/30 (2,5,2,3,5,3); CloudEagle 18/30 (3,4,2,3,4,2); QT9 16/30 (2,4,2,3,2,3). The subscription-management candidates have less certain native export paths. QT9's regulated validation scope is a poor fit for this lane. They were not registered.
