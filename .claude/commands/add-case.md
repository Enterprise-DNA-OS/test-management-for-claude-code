# add-case

Read CLAUDE.md and docs/cli.md. Write a draft test case.

Run `npm run testing -- add-case --project="<project>" --title="<title>" --priority="<priority>" --refs="<refs>" --steps="<steps>" --expected="<expected>" --actor="<actor>"`. Use values the operator supplies. Every read supports --json.

Read the affected record before changing it. Actor names are attribution, not authentication. Use the operator’s identity and evidence. Never invent evidence or approval.

No command sends a message, deploys a release or changes a vendor system.
