# Why there is no front end

The weekly jobs are finding unfinished checks, assigning retests, recording evidence and preparing a release review. These can run against a database through the command recipes, with printable reports for people who need to read them. npm run view renders two read-only snapshots. npm run docs renders release evidence, defect follow-ups and test-data review records in the business's brand.

An interactive testing workspace adds concurrent editing, browser forms, mobile and offline capture, drag-and-drop planning, notifications and direct test-tool connections. The free base has no such application. It does not execute tests or collect browser recordings. Local mode is for one operator at a time. Shared use needs a configured database and access controls.

TestRail already offers reporting, integrations and an agent connection. This build's benefit is owning and changing the workflow. It does not depend on a claim that TestRail cannot answer a particular question.

For a team that needs forms, live test-tool connections or different approval rules, Enterprise DNA can build these into its version. Start with a real release and decide which interactions the team needs. Omni by Enterprise DNA offers a setup fee followed by a retainer for a managed system.
