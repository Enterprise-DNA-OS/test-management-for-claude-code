# add-project

Read CLAUDE.md and docs/cli.md. Register a project with a data-retention review.

Run `npm run testing -- add-project --name="<name>" --owner="<owner>" --review-due="<review-due>" --retention="<retention>" --actor="<actor>"`. Use values the operator supplies. Every read supports --json.

Read the affected record before changing it. Actor names are attribution, not authentication. Use the operator’s identity and evidence. Never invent evidence or approval.

No command sends a message, deploys a release or changes a vendor system.
