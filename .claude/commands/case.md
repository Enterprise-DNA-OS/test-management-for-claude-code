# case

Read CLAUDE.md and docs/cli.md. Read a case with its history and run snapshots.

Run `npm run testing -- case --case="<case>"`. Use values the operator supplies. Every read supports --json.

Report what the records say. List ambiguous matches and ask the operator to choose. No guessing.
