# review-data

Read CLAUDE.md and docs/cli.md. Record a test-data purpose and retention review.

Run `npm run testing -- review-data --project="<project>" --review-due="<review-due>" --retention="<retention>" --actor="<actor>"`. Use values the operator supplies. Every read supports --json.

Read the affected record before changing it. Actor names are attribution, not authentication. Use the operator’s identity and evidence. Never invent evidence or approval.

No command sends a message, deploys a release or changes a vendor system.
