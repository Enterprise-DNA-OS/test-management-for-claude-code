# create-run

Read CLAUDE.md and docs/cli.md. Snapshot the approved case library into a new run.

Run `npm run testing -- create-run --project="<project>" --name="<name>" --build="<build>" --environment="<environment>" --due="<due>" --actor="<actor>"`. Use values the operator supplies. Every read supports --json.

Read the affected record before changing it. Actor names are attribution, not authentication. Use the operator’s identity and evidence. Never invent evidence or approval.

No command sends a message, deploys a release or changes a vendor system.
