# add-defect

Read CLAUDE.md and docs/cli.md. Track a defect against an included check.

Run `npm run testing -- add-defect --run="<run>" --case="<case>" --title="<title>" --ref="<ref>" --owner="<owner>" --severity="<severity>" --actor="<actor>"`. Use values the operator supplies. Every read supports --json.

Read the affected record before changing it. Actor names are attribution, not authentication. Use the operator’s identity and evidence. Never invent evidence or approval.

No command sends a message, deploys a release or changes a vendor system.
