# revise-case

Read CLAUDE.md and docs/cli.md. Revise a case and clear its approval.

Run `npm run testing -- revise-case --case="<case>" --title="<title>" --priority="<priority>" --refs="<refs>" --steps="<steps>" --expected="<expected>" --actor="<actor>"`. Use values the operator supplies. Every read supports --json.

Read the affected record before changing it. Actor names are attribution, not authentication. Use the operator’s identity and evidence. Never invent evidence or approval.

No command sends a message, deploys a release or changes a vendor system.
